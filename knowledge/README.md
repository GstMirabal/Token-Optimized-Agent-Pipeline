# 🧠 Knowledge Matrix: Long-Term Memory (LTM) Layer

Architectural manual for the management, distillation, and purge of agent intelligence within the Universal-Agents framework.

## 1. Tactical Purpose
This directory stores **Exotic Heuristics** and non-obvious technical solutions discovered during tactical sprints. It functions as the permanent brain of the Matrix, ensuring collective intelligence survival across sessions (Rule 74).

## 2. Domain-Based Architecture (Rule 75)
Knowledge Items (KIs) MUST be categorized into domain-specific subdirectories to ensure structural scalability and token-saving during discovery phases.

| Domain | Tactical Scope |
| :--- | :--- |
| **`/crypto/`** | Advanced security workarounds, cryptographic hash implementations, and ARM64-specific library bug-fixes. |
| **`/visuals/`** | Premium communication assets following Rule 11 (Mermaid strategies, comparative table layouts, and UX/UI standards). |
| **`/utility/`** | Survival heuristics for environment hangs, tool remediation, and IDE/API freezes. |

## 3. The Semantic Index (`ki_index.json`)
The `ki_index.json` file acts as the **Orchestrator's Quick-Reference Map**. Before reading full content from `.md` files, the Orchestrator MUST query the index for high-density 1-line semantic summaries to optimize context window usage.

## 4. The Amnesia & Purge Mandate (Rule 74 Pt 4)
The Matrix prioritizes **High-Signal Knowledge over Archival Noise**. To prevent cross-session context pollution, knowledge Project items MUST be purged if:
1. The discovery is successfully codified into the Constitutional Rules (Rules 1-78).
2. The finding refers to obsolete or deprecated infrastructures.
3. The intelligence becomes redundant with a newly established governance law.
