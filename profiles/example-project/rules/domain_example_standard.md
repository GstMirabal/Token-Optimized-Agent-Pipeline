# Rule: Domain Example Standard

Illustrative project-family rule — shows the shape a profile-scoped rule takes, not a real convention.

| Category | Rule (Key) | Value / Constraint (Value) |
| :--- | :--- | :--- |
| **Data Normalization** | `example_source_priority` | When merging data from multiple example sources, prefer `source_a` over `source_b` on conflict. |
| **Naming** | `example_entity_prefix` | Domain entities in this fictional project are prefixed `Ex` (e.g. `ExOrder`, `ExCustomer`). |
