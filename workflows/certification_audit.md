# 🛡️ Workflow: Global Certification Audit (Agnostic)

This workflow performs a comprehensive health check of the repository, ensuring it meets the 100% Core compliance standards of the Universal-Agents framework, regardless of the underlying stack or ORM.

## 📋 Execution Steps

### 0. Scoping & Roadmap Initialization (Token-Saver)
- **Token Efficiency (MANDATORY):** If auditing modules with files > 200 lines, the Orchestrator MUST execute the `omni-context-minimizer` FIRST to extract the structural skeleton and avoid context bloating.
- **Map Implementation:** Identify implemented modules vs. uninitialized boilerplate.
- **Incremental Audit:** Determine which areas have changed since the last certification.
- **Define Target:** Create or update **`docs/roadmaps/certification_roadmap.md`** (High-Value Deliverable) listing the modules to be audited.
- **Exclusion Zone:** Explicitly exclude `.agents/governance/` and metadata-only folders from automated scans (Linting, Typing, SAST).

### 1. Environment & Configuration Check
- Verify runtime environment (e.g., Python, Node.js, Go) and dependency versions (support for `uv`, `pnpm`, `pip`, etc.).
- Run framework-specific configuration validation (e.g., `django check`, `npm run build`).
- Ensure required environment variables (`.env`) are present.

### 2. ORM & Database Schema Integrity
- **Migration Check:** Verify if there are pending schema changes (`makemigrations --check`, `prisma migrate status`).
- **Sync Validation:** Ensure migration history is linear.
- **ORM Audit:** Check for missing indexes or N+1 risks in models within the **implemented scope**.

### 3. Code Quality & Static Analysis
- **Quality Audit:** Run standard tools (`Ruff`, `ESLint`, `Mypy`, `Pyright`, `TypeScript`).
- **Complexity:** Review cyclomatic complexity only for the **scoped modules**.

### 4. Security & Production Readiness
- **Dependency Scan:** Audit for vulnerable packages (`Safety`, `npm audit`, `Snyk`).
- **SAST Audit:** Perform Static Application Security Testing (`Bandit`, `Semgrep`).
- **Cloud/Deploy Audit:** Verify production settings (SSL, headers, secure cookies, debug off).

### 5. Documentation & Technical English
- **Sanitization:** Scan for non-technical strings or locale-specific remnants.
- **Standard:** Ensure all docstrings follow the English Technical Standard (Google Style or JSDoc).
