# 🛡️ Workflow: Global Certification Audit

This workflow performs a comprehensive health check of the repository, ensuring it meets the 100% Core compliance standards of the Universal-Agents framework.

## 📋 Execution Steps

### 1. Environment & Database Check
- Verify virtual environment and python version.
- Run `python manage.py check` to catch configuration errors.
- Run `python manage.py makemigrations --check` and `python manage.py showmigrations --check` to ensure database integrity.

### 2. Code Quality & Typing
- Run `make lint` to audit PEP8 and logic rules (Ruff).
- Run `make type-check` to verify strict typing compliance (Mypy).
- *Note: On Python 3.13, external stubs errors are expected and documented in KI-002.*

### 3. Security Audit
- Run `make safety` to check for vulnerable dependencies and source code security (Bandit).
- Run `python manage.py check --deploy` to audit production-ready settings.

### 4. I18n & Sanitization
- Scan for non-technical strings or Spanish remnants in core and secondary modules.
- Ensure all docstrings follow the Google Style protocol in English.

## 🏁 Certification Report
The result of this workflow must be updated in `docs/MASTER_AUDIT_REPORT.md` and the status reflected in `task.md`.
