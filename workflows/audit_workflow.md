# 🛡️ Workflow: Audit (The Inquisitor Protocol)

A non-tactical governance protocol engineered to verify structural, topological, and legal integrity across the Matrix environment. No business logic or product features are developed during this workflow.

## 0. Constitutional Invocation (Phase 0)
- **Zero-Memory State:** All executing subagents MUST initialize with absolute zero local memory.
- **Role Isolation:** The **[Rule Validator](../agents/rule_validator.md)** acts as the supreme coordinator of this protocol.

## 1. Topological Sweep (@rule_validator)
1.  **Rule Introspection:** Systematically cross-reference the `rules/` directory against `agents.md`. Highlight overlaps, contradictions, or numeric rule citations broken by Constitution updates.
2.  **Arsenal Certification:** Read `skills/manifest_skills.json`. Physically verify that every single named skill natively exists in `skills/` and legally adheres to the **Trinity Standard** and `-3rd` nomenclature.
3.  **Jurisdictional Limits:** Confirm no sub-folders like `core/` or `local/` have been unconstitutionally re-created inside `skills/`.

## 2. Documentary Purity (@doc_orchestrator)
1.  **Nomenclature Scrutiny:** Crawl `docs/sprints/` and `docs/roadmaps/`. Report and forcibly auto-correct any file evading the `[layer]/[app]/` dictionary structure.
2.  **Linguistic Enforcement:** Scan active roadmaps and contracts for non-Technical English vocabulary (Rule 1). Translate and sanitize immediately.
3.  **Link Broken Auditing:** Execute `ki_013_broken_link_audit_protocol.md` patterns to ensure no internal `.md` file points to an eradicated `core/` topological path.

## 3. Telemetry Processing (@qa_agent)
1.  **Memory Digestion:** Analyze `/memory/telemetry/proposals.md`.
2.  **Jurisprudence Implementation:** If formal system telemetry mandates changes, the QA Agent MUST authorize the Rule Validator to amend `agents.md`.

## 4. Final Verdict and Reporting
- Generate a conclusive `matrix_audit_report.md` artifact (Ephemeral) detailing discrepancies found and neutralized.
- Present the artifact to the Human User for final transparency.
- Exit and **SESSION LOCKED**.
