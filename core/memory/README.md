# .agents / Memory Hub

Directorio dinámico para el almacenamiento local de contexto volátil (El Loop de Jurisprudencia).
Todo archivo transitivo creado aquí sigue el mandato **Scope Strict & Amnesia** dictado por la Constitución matriz (`agents.md`):

1. **Efímero:** Los bugs resueltos generan markdowns que actúan como "Jurisprudencia Temporal".
2. **Escalado Governance:** Todo file documentado espera a que el *Governance Learner* extraiga el patrón para inyectarlo como regla técnica en `agents.md`.
3. **Namespaces Aislados:** La lecto-escritura debe limitarse siempre a un namespace asilado de pertenencia (ej. `/core/` o `/cryptobot/`).
4. **Proxy de Contexto:** El agente tiene terminantemente prohibido listar recursivamente los subdirectorios. El enrutamiento debe limitarse a parsear e imprimir los descriptores hiper-condensados (1 línea) de los ficheros `memory_index.json` localizados.
